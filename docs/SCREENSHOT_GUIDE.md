# Moviq Screenshot & Visual Asset Guide

Guidelines for capturing high-resolution visual screenshots for repository presentation, portfolio case studies, and documentation.

---

## 1. Screenshot Capture Standards

- **Viewport Size**: `1920 x 1080 px` (Full HD Desktop)
- **Browser Theme**: Chrome / Edge dark mode with scrollbars hidden.
- **DPI**: `2x` Retina / High-DPI display scaling.
- **Sample Data**: Use production prompts (e.g., *"A luxury perfume bottle rotating on black marble with warm golden caustics"*).
