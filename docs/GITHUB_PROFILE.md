### Long Description
> Moviq is a production-grade AI video generation studio designed with a modular, provider-independent backend architecture. It unifies commercial cloud video models (Kie Kling 3.0, Veo 3.1, Luma Dream Machine, MiniMax Hailuo) and self-hosted open-source models (Hugging Face Wan 2.2, Remote Wan, LTX Video) under a single FastAPI service layer. Features live provider health telemetry, a rule-based AI recommendation engine, smart failover, a 13-stage microsecond event timeline, and computer vision motion validation using OpenCV.
